# i18n Rules

- ICU MessageFormat for plurals, selects and interpolation; never concatenate translated fragments
- Keys are semantic (`checkout.payButton`), not the English text
- Every key exists in the default locale; missing keys fall back and are reported in development
- Add translator context for ambiguous strings
- Dates, numbers, currencies and lists format through `Intl` with explicit locale and time zone
- Locale lives in the URL (prefix or domain) with `hreflang` alternates; never trap users in a detected locale
- Machine translations of legal or marketing copy are flagged for human review
